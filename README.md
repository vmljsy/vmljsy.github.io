# Vimal Joshy — Portfolio

Personal developer portfolio and showcase for **Vimal Joshy** (Data Scientist & ML Engineer at IQVIA, NIT Calicut Alum).

Built with a clean **shadcn/ui-inspired** aesthetic, featuring a sleek zinc palette, modern typography, responsive layout, dark/light theme switching, and interactive components.

## Highlights
- **Design System**: shadcn/ui-inspired design tokens, zinc slate palette, glassmorphism header, and modern card components.
- **Theme Modes**: Native dark and light mode support with automatic system preference detection and local storage persistence.
- **Projects Showcase**: Interactive tab filtering (`All`, `AI & Machine Learning`, `Automation & Tools`) highlighting [Data Science Playground](https://vmljsy.github.io/ds-playground/), Flu Season Drug Sales Forecaster (Spain - Hackathon Runner-Up), Patient Cohort Creator (Hackathon Winner), and enterprise automation tooling.
- **Key Honors**: 2x Ovation Award recipient at IQVIA, Hackathon Winner & Runner-Up, and Corporate Bronze Award.
- **Direct Resume Access**: Downloadable PDF resume (`resume.pdf`).
- **Interactive Features**: 1-click clipboard email copy with custom shadcn-style toast notification.

## Tech Stack
- HTML5 (Semantic, Accessible)
- CSS3 (Custom Variables, Flexbox/Grid, Glassmorphism, Responsive)
- JavaScript (Vanilla ES6+, No external dependencies)
- Fonts: Google Fonts (Inter, JetBrains Mono)
- Icons: Font Awesome 6.5.1
